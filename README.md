# Mubit Memory has moved

This repository is archived and read only. Development, releases and issues
all live at **https://github.com/mubit-ai/plugins**.

## If you installed from here

This copy stays at version 0.13.2 and will never update. Switch to the new
marketplace:

```
/plugin marketplace remove mubit
/plugin marketplace add mubit-ai/plugins
/plugin install mubit-memory@mubit
```

Then start a new Claude Code session. Your memory is stored in your Mubit
instance, not in this repository. If the plugin asks you to sign in again, run
`/mubit-memory:auth`.

On the Codex CLI:

```
codex plugin marketplace add mubit-ai/plugins
```
